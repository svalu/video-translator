페이지 통째 번역 (크롬 확장 프로그램)   만든 사람 · 희랑

크롬의 '한국어로 번역'이 못 건드리는 곳까지 한국어로 바꿉니다.
예: 줌 파트너 강의처럼, 페이지 안에 다른 사이트의 강의 재생기를 창으로 끼워 넣은 화면.

────────────────────────────────
설치 (한 번만)
────────────────────────────────
  1. 크롬 주소창에  chrome://extensions  입력
  2. 오른쪽 위 [개발자 모드] 켜기
  3. 왼쪽 위 [압축해제된 확장 프로그램을 로드합니다] → 이 page_translator 폴더 선택
  4. 주소창 오른쪽 퍼즐 조각 → '페이지 통째 번역' 옆 압정을 눌러 고정

  ※ [개발자 모드]가 회색으로 잠겨 있으면 회사 정책으로 막힌 것 — 이 PC 에선 못 씁니다.
     (그럴 땐 동영상 동시 통역기의 화면 번역 Ctrl+Shift+T 를 쓰세요)

────────────────────────────────
쓰기
────────────────────────────────
  번역할 페이지에서 확장 아이콘을 누르거나 Alt+T.
  아이콘에 파란 '한' 표시 = 켜짐. 다시 누르면 영어로 되돌아갑니다.
  켜 둔 탭은 다음 장으로 넘어가도, 새 글이 떠도 계속 번역합니다.

────────────────────────────────
알아 둘 것
────────────────────────────────
  · 누를 때만 동작합니다. 켜지 않은 탭의 내용은 읽지 않습니다.
  · 켠 페이지의 글자는 번역을 위해 구글 번역으로 보냅니다. 회사 기밀 문서가 뜬 페이지에서는 켜지 마세요.
  · 영상 속 말소리, 그림 안의 글자는 번역하지 못합니다 → 동영상 동시 통역기(말 번역 · 화면 번역)를 쓰세요.
  · 문장 중간에 굵은 글씨·링크가 섞이면 조각조각 번역돼서 어색할 수 있습니다.
  · 코드 칸, 입력 칸은 건드리지 않습니다.
