처음 써 보는 분처음 설치하기
  1. 위의 Windows 버전 다운로드를 눌러 zip 을 받아요.
  2. 원하는 폴더에 압축 풀기 해요. 설치는 없어요. (zip 안에서 바로 누르지 마세요)
  3. VideoTranslator.exe 를 더블클릭해요. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.
  4. 처음 켜면 준비 점검 카드가 열려요. 빨간 줄 옆 버튼을 위에서부터 누르면 번역 엔진(Ollama)과 번역 모델까지 알아서 받아요.
  5. 영상을 틀고 읽기 시작. 슬라이드가 보이면 Ctrl+Shift+T.

잠깐 막혔나요?

자주 묻는 질문

여기서 먼저 확인해 보세요.

돈이 드나요?

아니요. 앱·번역 엔진(Ollama)·번역 모델·목소리 모두 무료예요. 유료 번역 서비스나 구독을 쓰지 않아요.

영상이나 내 화면이 어디로 보내지나요?

말 번역은 내 PC 안에서만 해요. 영어 문장이 밖으로 나가지 않아요.

화면 번역은 빠르게 하려고 슬라이드에서 읽은 영어 글자만 구글 번역으로 보내요. 화면 사진은 보내지 않아요. 구글이 안 되면 내 PC 모델로 대신해요.

목소리는 Microsoft Edge 목소리(인터넷)를 쓰고, 안 되면 윈도우 기본 목소리로 읽어요.

"Windows의 PC 보호" 창이 떠요.

처음 받은 프로그램이라 Windows 가 한 번 확인하는 화면이에요. 추가 정보를 누르면 나오는 실행을 누르세요.

'실시간 자막'이 영어(미국) 음성 팩을 받으라고 해요.

윈도우 11 의 실시간 자막을 처음 켤 때 한 번 나오는 안내예요. 받아 주세요. 그 뒤로는 앱이 알아서 켜고 숨겨요.

그래픽카드가 없어도 되나요?

돼요. 준비 점검이 그래픽 메모리가 작거나 없으면 작은 번역 모델(EXAONE 2.4B, 약 1.6GB)을 골라요. 대신 문장당 몇 초 더 걸려서, 동시통역보다는 자막 보조에 가까워요.

회사 업무에 써도 되나요?

말 번역에 쓰는 EXAONE 3.5 모델은 비상업(연구·개인 공부) 라이선스예요. 개인 공부용으로 쓰시고, 업무·서비스에 쓰려면 먼저 만든 사람에게 물어봐 주세요.

지우려면요?

압축 푼 폴더를 지우고, %LOCALAPPDATA%\VideoTranslator 폴더도 지우면 돼요. Ollama 는 [설정 → 앱]에서 제거하고, 받은 모델은 %USERPROFILE%\.ollama 에 있어요.
